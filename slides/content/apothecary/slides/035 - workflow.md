## How the exercises work

| | |
| --- | --- |
| Work on one | `./sake ex 01-cauldron`: edit `exercises/01-cauldron/start/`, the page reloads |
| Peek at the answer | `./sake ex-solution 01-cauldron` |
| Start over | `./sake reset-ex 01-cauldron` |
| Every command | `./sake` |

Stuck? Raise your hand: helpers are walking around.

## Speaker notes

Resets: `reset-ex <ex>`, `reset-widget <name>`; `reset-all` (rehearsal clean-up) discards everything.
Answers come from the `solutions` branch, fetched on demand.

## How the exercises work

| | |
| --- | --- |
| Pick one to work on | `./sake ex 01-cauldron`.{{br}}Next, edit `exercises/01-cauldron/start/`,{{br}} the page reloads on edit |
| Run the solution | `./sake ex-solution 01-cauldron` |
| Reset if needed | `./sake reset-ex 01-cauldron` |
| List every command | `./sake` |


## Speaker notes

Resets: `reset-ex <ex>`, `reset-widget <name>`; `reset-all` (rehearsal clean-up) discards everything.
Answers come from the `solutions` branch, fetched on demand.
